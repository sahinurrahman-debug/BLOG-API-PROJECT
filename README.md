<p># 📝 Blog API

A RESTful Blog API built with **FastAPI**, designed to provide a clean, scalable, and high-performance backend for managing blog posts and users.

The project demonstrates modern backend development concepts including API routing, request validation, database integration, authentication, CRUD operations, and automatic API documentation.

---

## 🚀 Features

- ✅ Fast and lightweight REST API using FastAPI
- ✅ Create, read, update, and delete blog posts
- ✅ User registration and authentication
- ✅ Secure password handling
- ✅ JWT-based authentication
- ✅ Database integration using SQLAlchemy
- ✅ Request and response validation using Pydantic
- ✅ Dependency injection with FastAPI
- ✅ HTTP status code handling
- ✅ Interactive Swagger API documentation
- ✅ ReDoc API documentation
- ✅ Modular and maintainable project structure
- ✅ Error handling and validation
- ✅ Easily extendable architecture

---

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| **Python** | Backend programming |
| **FastAPI** | REST API framework |
| **Uvicorn** | ASGI server |
| **SQLAlchemy** | ORM / database interaction |
| **Pydantic** | Data validation |
| **PostgreSQL / SQLite** | Database |
| **JWT** | Authentication |
| **Passlib / bcrypt** | Password hashing |
| **Swagger UI** | Interactive API documentation |
| **ReDoc** | API documentation |
